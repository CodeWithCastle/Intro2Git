# INTRODUCTION TO GIT

## Tutorial Brief
_This is a super simplified Git tutorial — like Git for humans, not robots._
_We decode the wizardry of `add`, `commit`, `push`, and other arcane spells._
_Think of branches as alternate universes for your code — no paradoxes, promise._
_You'll learn to clone stuff (legally), stash your mess, and time-travel with commits._
_Merge conflicts? Like sibling fights — awkward, but fixable._
_Basically, it’s Git without the existential crisis. You got this._
